# To-Do List

A simple and modern To-Do List application built with HTML, CSS and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Search and filter tasks
- Task counter
- Completed task counter
- Save tasks with Local Storage
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Preview

A modern To-Do List interface with separate sections for active and completed tasks.
